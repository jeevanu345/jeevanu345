I build software to explore how systems coordinate, how AI agents use feedback, and how ideas become working applications. My work spans distributed storage in Rust, execution-based code repair, retrieval-augmented learning tools, and full-stack applications.

As I prepare for graduate study in computer science, I’m particularly interested in **distributed systems, reliable AI, and the intersection of machine learning and software engineering**.

## Selected work

### [RaftKV](https://github.com/jeevanu345/raftkv)
**Distributed systems · Rust · gRPC**

An educational Raft-replicated key-value store with a Redis-compatible RESP2/RESP3 interface. Separates deterministic consensus logic from runtime I/O, with persistent logs, snapshots, cluster simulation, and a linearizability checker.

[Explore the code](https://github.com/jeevanu345/raftkv) · [Architecture](https://github.com/jeevanu345/raftkv/blob/main/ARCHITECTURE.md)

### [Code-Repair Agent](https://github.com/jeevanu345/Code-Repair-Agent-with-Execution-Grounded-RL-on-SWE-Bench)
**AI for software engineering · Python · Reinforcement learning**

An experimental framework for software repair on SWE-bench using execution-grounded reinforcement learning. Connects repository tools, Docker-based test execution, and GRPO training; benchmark evaluation results are pending.

[Explore the code](https://github.com/jeevanu345/Code-Repair-Agent-with-Execution-Grounded-RL-on-SWE-Bench)

### [NCERT RAG Bot](https://github.com/jeevanu345/NCERT-RAG-Bot)
**Applied AI · Retrieval-augmented generation · Education**

An experimental local tutor for Class 10 NCERT material, exploring retrieval-augmented question answering in an educational setting.

[Explore the code](https://github.com/jeevanu345/NCERT-RAG-Bot)

### [TapCart](https://github.com/jeevanu345/TapCart)
**Full-stack development · Next.js · Retail workflows**

A prototype NFC-oriented retail ordering and inventory platform, bringing customer-facing interactions and operational workflows into one application.

[Explore the code](https://github.com/jeevanu345/TapCart)
